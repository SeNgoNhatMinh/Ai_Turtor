Read only additional rules/references needed for the current task.

## Workflow
1. Read design-system and accessibility rules. Identify role, learning task, information priority and constraints from real screen content.
2. Inspect current tokens and wrappers; identify specific visual weaknesses rather than defaulting to a generic dashboard.
3. Propose a coherent direction covering semantic color, typography, spacing, surfaces, icon treatment, navigation and restrained motion.
4. Demonstrate one representative mobile screen with Vietnamese labels and realistic long/empty/error content. Label mock content clearly.
5. Keep design exploration read-only unless mockup/code creation is authorized. New image assets require appropriate image tooling and user scope; don't add packages for a sketch.
6. For implementation, hand the approved brief to ai-tutor-redesign and evolve shared tokens. Do not change roles, API calls or feature behavior for visual symmetry.

## Deliver
A concrete visual brief, representative layout description or authorized prototype, token changes and acceptance criteria.
