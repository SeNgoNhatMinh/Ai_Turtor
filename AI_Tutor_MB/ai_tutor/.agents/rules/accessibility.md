# Mobile UX and accessibility
- Test narrow phone, normal phone, tablet, landscape, keyboard visible and safe insets.
- Check large system text (including 200%), Vietnamese diacritics, long labels and multiline errors.
- Target at least 48 logical-pixel interactive hit areas; do not rely on color alone.
- Use semantic labels, focus order, screen-reader announcements and accessible contrast.
- Respect reduced-motion settings. Animation must not block reading or input.
- Chat must preserve scroll behavior, draft, keyboard action, pending state and cancellation.
- Quiz must preserve selected answers, submission state, result and retry behavior.
- Never claim accessibility certification from screenshots alone.
