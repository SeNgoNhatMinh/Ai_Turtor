Các endpoint local khi chạy bằng Docker Compose:

  • Backend API: http://localhost:8085/actuator/health
  • Swagger UI (HTTP Basic): http://localhost:8085/swagger-ui/index.html
  • OpenAPI JSON: http://localhost:8085/v3/api-docs
  • n8n Editor: http://localhost:5678
  • Elasticsearch: http://localhost:9200

Swagger dùng tài khoản trong .env.deploy: SWAGGER_USERNAME / SWAGGER_PASSWORD.
